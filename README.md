
# Tuxborn Companion

The **Tuxborn Companion** aims to aid player of the <a href="https://github.com/Omni-guides/Tuxborn">Tuxborn modlist</a> in navigating the great amount of content included.

Currently, the companion comprises of a <a href="https://docs.google.com/spreadsheets/d/1HzoB06GWpWGvLCa3qLuvxmsM4Q5IZp-GYvYIKLLCM1A/edit?gid=1883312431#gid=1883312431">mod checklist</a> as a Google Sheets document and a related <a href="https://kahootics.github.io/Tuxborn_Companion/">web site</a>, currently in development.
